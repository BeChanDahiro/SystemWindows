✅ Cách Dùng Đơn Giản Nhất

Không cần lệnh phức tạp — tải trực tiếp về máy là chắc chắn nhất!


  1. Mở kho GitHub: github.com/BeChanDahiro/SystemWindows
  2. Nhấp nút <> Code → Download ZIP
  3. Giải nén ra thư mục trên Desktop
  4. Nhấp chuột phải → Main.bat → Chạy với quyền quản trị viên

📌 Thông Tin Dự Án

Bộ công cụ bằng Batch, tối ưu hóa cho Windows 10/11 — không cần phần mềm phụ thêm.


✅ Hỗ trợ: Windows 10 (1903+) / Windows 11

🔑 Quyền: Quản trị viên

💾 Mã hóa lưu tệp: ANSI (tương thích tốt nhất)

❌ Đã bỏ: SystemLauncher.ps1 → Tải trực tiếp về máy là cách ổn định nhất ✅
