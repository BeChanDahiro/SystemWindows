## 📥 CÁCH TẢI VỀ MÁY — 2 CÁCH ĐƠN GIẢN

### ✅ CÁCH 1 — Tải toàn bộ 1 lần (NHANH NHẤT) ⭐ Khuyến nghị

| Bước | Thao tác |
|:---:|---|
| **1** | Mở trang dự án: **https://github.com/BeChanDahiro/SystemWindows** |
| **2** | Nhấp nút **<> Code** (màu xanh lá) → chọn **Download ZIP** |
| **3** | Tệp `SystemWindows-main.zip` tự động tải về |
| **4** | Mở thư mục **Tải về** → Nhấp chuột phải tệp `.zip` → **Giải nén ở đây** |
| **5** | Kéo thư mục vừa giải nén ra **Màn hình chính (Desktop)** |
| **6** | Mở thư mục → Nhấp chuột phải **`Main.bat`** → **Chạy với quyền quản trị viên** ✅ |

### ✅ CÁCH 2 — Tải từng tệp thủ công

| Bước | Thao tác |
|:---:|---|
| **1** | Tạo thư mục **`SystemWindows`** trên Desktop |
| **2** | Vào: https://github.com/BeChanDahiro/SystemWindows |
| **3** | Mở lần lượt từng tệp trong danh sách dưới đây |
| **4** | Nhấp dấu **"..."** ở góc trên bên phải → **Download file** |
| **5** | Lưu tất cả vào thư mục `SystemWindows` vừa tạo |
| **6** | Sau khi đủ 9 tệp → Nhấp chuột phải **`Main.bat`** → **Chạy với quyền quản trị viên** ✅ |

📋 **Danh sách 9 tệp cần tải đủ:**
```
1. Main.bat                    ← Tệp menu chính
2. Active_Win_Office.bat       ← Kích hoạt Windows & Office
3. Active_IDM.bat              ← Kích hoạt IDM
4. Don_Rac.bat                 ← Dọn rác hệ thống
5. GodMode.bat                 ← Bật chế độ Thần tài
6. Mouse_Properties.bat        ← Cấu hình chuột
7. Win_Debloat.bat             ← Gỡ ứng dụng rác
8. Windows_Toolbox.bat         ← Công cụ mở rộng
9. WinUtil_Tool.bat            ← Tối ưu hệ thống & game
```

> ⚠️ **QUAN TRỌNG**: Tất cả **9 tệp phải ở cùng một thư mục** — không tách ra riêng lẻ!

## 🚀 CÁCH DÙNG SAU KHI MỞ MENU

1. Menu hiện ra → **nhập số** tương ứng tính năng cần dùng → **Enter**
2. Ví dụ: gõ `8` → Enter → dọn rác tự động
3. Xong tự động quay về Menu chính
4. Gõ `11` → Enter để **thoát an toàn**

> 💡 **Không chạy từng tệp con riêng lẻ** — Luôn mở từ `Main.bat` để đảm bảo đúng đường dẫn!
